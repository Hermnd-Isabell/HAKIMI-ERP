# HAKIMI ERP 设计补充与变更记录

此文档用于记录在开发实现阶段，为了满足业务逻辑闭环（特别是对齐 SAP 标准 O2C 流程）而对《逻辑模型设计报告》进行的字段补充与表结构变更。

## 1. 字段补充说明 (Field Additions)

以下字段在原始设计报告的 DDL 表格中未定义，但在实现过程中为支撑业务功能而增加。

### 1.1 物料主数据 (Material)
*   **category**: 产品类别（如：成品、原材料）。
*   **stock_quantity**: 当前库存数量（实物库存）。
*   **item_group**: 物料组（用于销售统计和定价）。
*   **status**: 物料状态（ACTIVE/INACTIVE）。

### 1.2 交货抬头 (Delivery)
*   **carrier**: 承运商名称。
*   **driver_name**: 司机姓名。
*   **route**: 运输路线。
*   **tracking_no**: 物流追踪单号。
*   *增加目的：为了模拟完整的物流运输和发货跟踪环节。*

### 1.3 交货行项 (DeliveryItem)
*   **order_quantity**: 关联订单的原始数量（用于校验）。
*   **picked_quantity**: 已拣货数量。
*   **plant**: 发货工厂代码。
*   **storage_location**: 发货库位。
*   **item_status**: 行项目状态（OPEN/PICKED/PGI_DONE）。
*   *增加目的：支撑 SAP 标准的“拣货 -> 确认 -> 过账”三步走逻辑，实现分批拣货。*

### 1.4 财务凭证 (Invoice & Receipt)
*   **Invoice.remark / Receipt.remark**: 单据备注。
*   **Invoice.search_term / Receipt.search_term**: 辅助检索关键词（对齐 BP 设计）。

## 2. 结构对齐说明 (Alignment Fixes)

以下字段在《设计报告》的正文或字段列表中存在，但初期 SQL 脚本或模型实现时被遗漏，现已补全。

### 2.1 发票抬头 (Invoice)
*   **sales_org**: 销售组织。
*   **distribution_channel**: 分销渠道。
*   **division**: 产品组。
*   **shipping_point**: 装运点。
*   **destination_country**: 目的国代码。

---

## 3. 新增表结构 (New Tables)

为了使 ERP 系统具备基础的组织架构和运营能力，新增了以下支撑表：

1.  **sales_organization**: 存储销售组织、分销渠道、部门的组合定义。
2.  **pricing_condition**: 存储定价条件记录（如物料基础价格、客户折扣等）。
3.  **storage_location**: 存储仓库内的具体库位主数据。
4.  **pick_record**: 存储每一批次的拣货历史记录。

---

## 4. 故障排查提示 (Troubleshooting)

如果您在访问物流或财务页面时遇到 **500 Internal Server Error**，且日志提示 `Unknown column '...'`，通常是因为本地数据库未执行 `ALTER TABLE` 脚本同步上述变更。请确保数据库版本与最新的 `app/models/` 定义保持一致。
